# Task2 — Проектирование решения

В этой директории содержится контекстная диаграмма C4 целевого состояния системы «Медикаменте».

## Что добавлено по сравнению с As-Is

- **Privacy & Security Layer** — слой управления конфиденциальными данными (каталог, тегирование, RBAC/ABAC, KMS, аудит).
- **Data Minimization** — минимизация собираемых полей, TTL хранения, псевдонимизация/маскирование.
- **Privacy Enforcement Gateway (API)** — шлюз, через который проходят все интеграции (лаборатория, мобильное приложение).
- **Analytics & BI Layer** — слой аналитики с деперсонализацией данных, lineage и ограниченным доступом.
