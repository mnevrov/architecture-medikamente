# Controls & Tools — меры защиты по потокам

## Сквозные меры
- Шифрование на хранении (BitLocker/EFS для файлового сервера; при миграции — TDE в БД, объектное хранилище с SSE-KMS).
- Шифрование при передаче (TLS 1.2+, mTLS для API интеграций, S/MIME для почты).
- Аутентификация и доступ: AD + MFA, RBAC/ABAC, принцип наименьших привилегий.
- Логи и аудит: централизованный сбор (ELK/ClickHouse + VictoriaMetrics), неизменяемое хранилище, ретенция.
- DLP: контроль выгрузок/пересылок, водяные знаки на документах.
- Резервное копирование: 3‑2‑1, offsite/immutable, тесты восстановления, шифрование бэкапов.

## По процессам
- **Регистрация/запись**: формы с валидацией и минимизацией; маскирование контактов в списках; раздельные домены (идентификатор пациента ↔ клинические данные).
- **Платежи**: исключить PII из чеков/тем писем; перевести 1С в серверный режим; ролевая матрица; журналирование.
- **Лаборатория**: API‑шлюз с контрактами полей; токены с ограниченными scope; файловый обмен → SFTP с отдельным контуром и реестром передач (до API).
- **Медкарты**: шифрование на уровне поля; доступ только врач/пациент; «break‑glass» с обоснованием и алертом; антипечать/антискрин (DLP).
- **Склад**: журнал операций, контроль экспорта, сегментация сети.
