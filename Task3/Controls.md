# Инструменты и средства защиты данных

## Базовые инструменты

- Шифрование на хранении (TDE, EFS, BitLocker, SSE-KMS)
- Шифрование в передаче (TLS 1.3, mTLS для API, S/MIME для почты)
- Аутентификация/авторизация: IdP + MFA, RBAC/ABAC
- Резервное копирование: offsite + immutable, шифрование бэкапов
- Аудит: централизованный сбор логов (ELK, ClickHouse, VictoriaMetrics)

## Дополнительные инструменты

- **KMS** (Vault, AWS/Yandex KMS) — управление ключами
- **Data Catalog** (OpenMetadata, Collibra) — тегирование и lineage
- **ETL с анонимизацией** (Spark, Airflow, DeID) — деперсонализация для BI
- **DLP** — для почты и рабочих станций
- **API Privacy Gateway** (Kong/OPA) — контроль полей в API
- **Secrets Manager** (Vault, CyberArk) — хранение секретов
- **HSM** — аппаратные модули для ключей

## Автоматизированный контроль

- Release checks: CI/CD проверяет работу с тегами (PHI/PII)
- UEBA: анализ поведения пользователей, алерты на аномалии
- DLP: контроль выгрузки файлов и пересылки
- Политики ретенции: автоудаление устаревших данных
