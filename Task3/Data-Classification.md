# Классификация данных и методы защиты

| Данные | Необходимость защиты | Инструменты защиты |
|--------|-----------------------|---------------------|
| **Персональные данные (ФИО, ДР, телефон, email)** | PII, высокий риск утечки, требование ФЗ-152 | Шифрование БД (TDE/AE), TLS 1.3 при передаче, маскирование в логах, RBAC/ABAC, MFA |
| **Адреса, место работы/учёбы** | Высокая чувствительность, может использоваться для социальной инженерии | Минимизация хранения, шифрование на уровне поля, доступ только по ролям |
| **Медицинские данные (анамнез, диагноз, заключения, анализы)** | Особая категория ПДн (ФЗ-323), критический риск утечки | Сегментация домена CLINICAL, шифрование на уровне поля (KMS/AE), журналирование «break-glass» доступа, псевдонимизация для аналитики |
| **Финансовые данные (чеки, суммы, договоры)** | Требование законодательства и налоговых органов, риск мошенничества | Шифрование БД и резервных копий, TLS для интеграции с банком/ККМ, контроль целостности, DLP |
| **Документы (сканы паспортов, согласий, договоров)** | Содержат PII и PHI, высокий риск репутационных потерь | Хранение в зашифрованном хранилище (EFS/BitLocker/S3 SSE-KMS), водяные знаки, запрет пересылки, DLP |
| **Учётные данные (логины, пароли, токены)** | Критический риск компрометации всей системы | Vault/Secrets Manager, MFA, аппаратный HSM для ключей, запрет хранения паролей в файлах |
| **ТМЦ (накладные, серийные номера)** | Средний риск, коммерческая тайна | Шифрование БД, контроль доступа, аудит экспорта |
| **Технические логи (IP, устройства, события)** | Средняя чувствительность, могут раскрывать инфраструктуру | Маскирование IP, ротация логов, хранение в защищённом SIEM, RBAC на доступ к логам |
